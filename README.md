# 工业革命与人类发展

一套以**工业革命为主线**的知识库：从四轮革命的机制与组织变革出发，推导人类发展的共通规律，并落到当下的 Agent 平台判断。

**核心论点**：人类发展的动力，是「把稀缺变成不稀缺」；而每一轮发展的代价，是把新的稀缺制造出来。技术可用与生产率兑现之间，隔着一次组织重构。

## 目录结构

```
industrial-revolutions/
├── README.md          ← 本文件：项目说明
├── wiki/              ← 核心知识体系（Markdown，结论的权威来源）
├── visualization/     ← 静态可视化页面（HTML 站点，结论的可视化表达）
└── scripts/           ← 生成与校验脚本（维护用）
```

### 三者职责

| 目录 | 是什么 | 不是什么 |
|---|---|---|
| **`wiki/`** | 结论、机制、数据口径的**权威来源**。纯 Markdown，可 grep、可 diff、可被 Agent 直接引用 | 不是页面的复制 |
| **`visualization/`** | 自包含的静态站点，图表化呈现 + 树形导航，适合阅读与演示 | 不是知识的权威来源 |
| **`scripts/`** | 保证 10 个页面结构一致性的构建与校验工具 | 不是内容生产流水线（内容以 wiki 为准） |

**维护顺序**：事实先改 `wiki/` → 跑 `scripts/build.py` 同步页面 → 跑 `scripts/verify.py` 确认无回归。

## 快速开始

```bash
# 直接浏览（无需构建）
open visualization/index.html

# 构建：同步导航、页脚、编号与链接（幂等）
python3 scripts/build.py

# 只检查是否有待构建内容
python3 scripts/build.py --check

# 全站校验：链接 / 标签 / 导航 / 编号 / 页脚 / 术语计数 / 关键数字 / wiki 一致性
python3 scripts/verify.py

# 校验逻辑自测（改动 verify.py 后必须跑）
python3 scripts/test_verify.py
```

三个脚本都只用标准库，无需安装依赖。

## 两条口径声明

**一、分期采用中国通行口径**（18 世纪 60 年代 / 19 世纪 70 年代 / 20 世纪四五十年代 / 2010s），第三次革命的核心标志明确为**电子计算机的广泛应用**。其他口径（Schwab 1960s、产业经济学 1970s、德国 1947–2011 / 2011–）在文档中并列列出但**不采用**；对外引用时须先声明所用口径。

**二、术语用「电子计算机」而非「电脑」**：「电脑」通常只指个人计算机（PC），而本套文档追踪的是从 ENIAC 到 AI 工厂的完整电子计算机谱系。
