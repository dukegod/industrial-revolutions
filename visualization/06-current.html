三个硬约束

数据均标注一手来源与时间

约束一：内存墙

算力、内存带宽、互连带宽的增速已经脱节——这正是 AI 芯片「买了却用不满」的原因。

峰值算力
3.0× / 2年
内存带宽
1.6× / 2年
互连带宽
1.4× / 2年

折算 20 年：算力约 60 万倍、DRAM 带宽约 100 倍、互连约 30 倍（Gholami et al., 2024）。 用 Roofline 模型看，就是拐点右上移，更多负载落进 Memory-Bound 区域。

结论：算力扩张速度事实上受制于 12–18 个月前签下的内存长约，而不受制于芯片设计。

约束三：ISA 格局松动，但生态是硬门槛

RISC-V 处理器份额
≈25%

2026 年的三个标志性进展：

  • RVA23 服务器平台规范 1.0（2026-06 欧洲峰会）：统一 UEFI/ACPI、PCIe/IOMMU、BMC、RAS、安全启动，使跨品牌部署成为可能。
  • CPU 直连 GPU：RISC-V CPU 经 NVLink Fusion 与 NVIDIA GPU 硬件级互连，进入 AI 数据中心核心链路。
  • 边缘与车载规模化：车规 RISC-V 已上车量产；可穿戴领域出现头部厂商转向。

但三道门槛同时存在：各家自定义扩展互不兼容（技术方言）、软件适配周期常超一年、晶圆产能排产优先级低。

NVIDIA 已宣布 Vera Rubin 进入量产，2026 下半年经合作伙伴上市——它不再是「一颗 GPU」，而是包含 Rubin GPU + Vera CPU + NVLink 6 + ConnectX-9 + BlueField-4 + Spectrum-6 + Groq 3 LPU 的七芯片平台。

2027/2028 为路线图口径，非交付承诺。

同期的另一半：自研 ASIC 与推理专用化

Google TPU7x（Ironwood） — 第七代 TPU，Google Cloud 当前最新一代。双芯粒架构，每芯片 192GB HBM、约 7.37 TB/s，单芯片 BF16 峰值 2307 TFLOPs，Pod 规模 9,216 芯片。JAX 将每个芯片暴露为两个设备，需重新做拓扑编排。（文档更新 2026-09-16）

推理被拆成两段 — Prefill 算力密集、可用 DDR 方案；Decode 反复读权重与 KV Cache、内存敏感、仍需 HBM。这直接催生 prefill/decode 分离部署与 KV Cache 分层。（TrendForce, 2026-01）

网络侧成为一等公民 — DPU（BlueField-4）、PCIe Gen6 SSD（连续读 28 GB/s、随机读 550 万 IOPS）、SOCAMM2 低功耗内存模块，都是为「数据搬得动」而不是「算得动」服务。（GTC 2026, 2026-03）

不确定项与口径差异

对外引用前请先读这一节

五条需要注意的地方

  • 路线图 ≠ 交付：2027 / 2028 的平台为 NVIDIA 官方路线图口径，最终时间与配置可能变化；「量产」也不等于所有客户可立即获得。
  • RISC-V 25% 为行业机构口径（处理器颗数口径），非厂商营收口径，且高度集中于嵌入式与物联网，高端通用计算仍由 x86/ARM 主导。
  • TPU 代际命名存在差异：TrendForce 表格中出现 v7p / v8e / v8p 等命名，而 Google Cloud 官方文档明确「当前最新一代为 TPU7x (Ironwood)」且更新时间在 2026 年 9 月。本套文档以 Google Cloud 官方文档为准。
  • 「25% 份额」与「从技术验证走向规模化商用」并存：二者不矛盾——前者来自海量嵌入式出货，后者是数据中心等高价值场景的进展，中间仍隔着软件生态与产能两道门槛。
  • 「对 Agent 平台的 5 条推论」为推论：基于公开架构事实推导，非对特定内部系统的既成判断，落地前需结合真实负载数据校验。
