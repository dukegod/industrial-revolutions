A · 体系结构与指令集17 条

指令集架构 ISA

CPU 执行程序的契约：寄存器、指令编码、寻址方式与内存模型。它划定了硬件与软件的责任边界。

微架构 Microarchitecture

实现同一 ISA 的具体内部设计——流水线深度、分支预测器、执行单元、缓存层次。同一 ISA 可以有截然不同的微架构。

冯·诺依曼结构 Von Neumann

程序与数据共用同一存储、顺序取指执行的体系结构。「存储程序」是它留给后世的核心遗产。

存储程序 Stored-program

指令以数据形式存放在内存中、可读取与修改，执行程序不再需要每次重新物理接线。

精简指令集 RISC

指令少而规整、定长、寄存器多，便于流水线实现与编译器优化。RISC-V 属于此类。

复杂指令集 CISC

单条指令可完成多步操作、寻址方式丰富，以指令数换兼容性。x86 是典型代表。

流水线 Pipeline

把指令拆成取指/译码/执行/访存/写回等阶段并行重叠，用延迟换吞吐。

超标量与乱序执行 Superscalar, OoO

超标量靠多发射端口提高每周期指令数；乱序执行按就绪顺序发射以隐藏延迟，但需内存序保证正确性。

分支预测与推测执行 Branch prediction, Speculation

用历史统计猜测控制流走向并先行执行；预测失败要清空流水线。它同时是性能来源与 Spectre 类漏洞的源头。

存储层次 Memory hierarchy

寄存器 → 缓存 → 主存 → SSD → 远端存储的层级结构，靠时间与空间局部性做出「等效扩容」。

缓存三要素 Cache

命中时间、缺失率、容量。缓存命中与否直接决定这次访存是几纳秒还是几百纳秒。

内存墙 Memory wall

算力增速远超内存带宽增速，导致大量计算单元在等数据，系统实际吞吐远低于峰值。

内存模型与内存序 Memory model, ordering

多核访问内存的可见性与顺序规则。x86 较强、ARM/RISC-V 较弱，直接决定并行程序该怎么写才正确。

虚拟内存 / 页表 / TLB Page table, TLB

页表完成虚拟地址到物理地址的映射，TLB 缓存映射结果。它是进程隔离与容器化的基础。

IOMMU

把设备发起的 DMA 访问也纳入页表与权限控制，是 GPU 直连与设备级安全隔离的关键机制。

中断 / DMA / 异常

CPU 与外设协作的三种基本机制。中断是 I/O 密集型负载进入内核的主要入口，DMA 则让搬运不占 CPU。

RAS 机制 Reliability, Availability, Serviceability

数据中心的硬件级容错机制：纠错、故障隔离、热插拔与故障预测，是 7×24 运行的底座。

B · 并行与加速器19 条

对称多处理 SMP

多个处理器核共享同一内存空间与同一操作系统，是现代服务器的基本形态。

NUMA / CC-NUMA Non-uniform memory access

内存按节点绑定，跨节点访问更慢。远端内存带宽是集群扩展的真实上限，而非单卡算力。

超线程 SMT

同一物理核上跑多个硬件线程，用执行单元的空档换吞吐，不提升单线程峰值性能。

SIMD 与向量扩展 RVV, NEON, SVE

一条指令对多个数据并行计算。RISC-V 的 RVV 是开放且可定制的向量扩展路线。

算术强度 Arithmetic intensity

每搬运 1 字节数据能做多少次浮点运算。它直接决定一个负载是算力受限还是带宽受限。

Roofline 模型 Roofline

用可达算力与内存带宽两条线界定性能上限，拐点即「运算强度够不够」的分界线。

GPU

由大量简单计算单元构成的高度并行处理器。图形流水线演化为通用并行阵列后，成为 AI 算力主力。

CUDA

NVIDIA 的并行计算平台，含编程模型、库、工具链与运行时。它本身就是护城河，而不只是驱动。

矩阵单元 Tensor Core, MMA

专做矩阵乘加的硬件单元，低精度下吞吐可达通用单元的数倍，是推理加速的主引擎。

ASIC 与 NPU Application-specific IC

为特定负载定制的电路，能效最优但通用性差；NPU 是其面向端侧低功耗推理的形态。

数值格式 FP16, BF16, FP8, INT8, NVFP4

精度越低，显存占用与带宽压力越小、算力利用率越高，但对数值稳定性与校准的要求越高。

量化 Quantization

用更低位宽表示权重与激活以节省显存与带宽；分为训练后量化与需要校准的校准后量化。

KV Cache

注意力机制中缓存已生成 token 的键值对。容量随上下文长度与并发数线性增长，是推理显存占用的头号来源。

GQA / MQA Grouped / Multi-query attention

让多个查询头共享同一组 KV 头，显著压低 KV Cache 体积与解码阶段的带宽压力。

预填充与解码 Prefill / Decode

推理的两阶段：预填充一次性处理完整输入、算力密集；解码逐 token 生成、内存带宽密集。

连续批处理 Continuous batching

请求完成后立即把新请求补入空位，而非等整批结束。它直接决定推理服务的吞吐与排队时延。

投机解码 Speculative decoding

用小模型草拟多个 token 再由大模型并行验证，用额外算力换更低的单 token 时延。

张量 / 流水 / 序列并行

把一次前向计算切到多卡的三种方式，分别切矩阵、切层、切序列，对通信模式的要求各不相同。

集合通信原语 Collective, AllReduce

跨卡数据交换的基础操作，是分布式训练与推理的通信底座，其效率常成为实际瓶颈。

C · 存储与互连17 条

SRAM 与 DRAM

SRAM 速度快、无需刷新但面积大密度低，用作缓存；DRAM 密度高但需刷新，用作主存。

高带宽内存 HBM

垂直堆叠 DRAM 并与加速器同封装，靠超宽接口而非高频率取胜，是 AI 加速器的默认内存形态。

HBM 代际 HBM3E / HBM4 / HBM4E

接口宽度、传输速率与堆叠层数逐代提升。HBM4 把接口宽度翻倍至 2048-bit，单堆栈带宽进入 TB/s 级。

硅通孔 TSV, Through-silicon via

穿透硅片连接堆叠 DRAM 层的工艺，是 HBM 得以成立的关键，间距越小良率挑战越大。

堆叠层数 12H / 16H

单堆叠内的 DRAM 层数，直接决定单堆容量；层数越高，良率与散热越难。

GDDR / DDR5 / LPDDR

分别面向图形、服务器通用与终端低功耗的 DRAM 品类，容量与带宽取舍不同。

SOCAMM

面向 AI 服务器的低功耗高容量内存模块形态，定位在 HBM 与 DDR 之间，用于 CPU 侧大内存供给。

CXL Compute Express Link

在 PCIe 物理层上承载缓存一致互连，让 CPU、加速器与内存池共享同一套内存语义。

NVMe 与 PCIe Gen6

固态存储的协议与接口代际，持续推高顺序带宽与随机 IOPS，用于缓解数据墙。

显存 VRAM

加速器本地内存的通用称呼。HBM 时代，其容量与带宽直接决定可服务的模型规模与并发数。

NVLink

NVIDIA 的高带宽片间互连，用于同一域内 GPU 之间的 scale-up，版本随平台代际同步升级。

ICI Inter-chip interconnect

Google TPU 的芯片间互连，构成一个 Pod 内的 scale-up 域，拓扑为三维网格。

InfiniBand / RDMA / RoCE

数据中心无损网络与远程直接内存访问技术，让网络访问接近内存语义，降低通信开销与 CPU 占用。

Scale-up / Scale-out / Scale-across

同域扩加速器、跨节点扩集群、跨机架扩集群三级扩展，三者瓶颈位置与网络要求完全不同。

NVL72 / NVL144

NVIDIA 机架级 scale-up 域规格，分别把 72 / 144 个 GPU 纳入单一高速互连域。

3D torus / mesh 拓扑

集群内芯片互连的常见拓扑，决定了全归约等集合通信的效率与扩展性。

共封装光学 CPO

把光引擎与交换芯片共封装，降低高速互连的功耗与距离损耗，是下一代 scale-out 的候选方案。

D · 系统、集群与数据中心12 条

域内与域外通信

域内由芯片互连决定带宽与延迟，域外退化为网络问题。扩展规模前先确认请求落在哪一侧。

液冷 Direct-to-chip

把冷却液送到芯片附近直接带走热量，是高密度机柜的必需配套，而非可选项。

机柜功率密度与供电

单机柜功率从十几千瓦走向上百千瓦，供电、配电与机柜改造成为机房建设的硬约束。

PUE Power Usage Effectiveness

数据中心总能耗与 IT 设备能耗之比，衡量基础设施效率，不反映 IT 设备本身的能效。

前端网络 / 后端网络

面向外部请求与集群内部东西向流量的两张网络，二者的容量规划与故障域完全不同。

调度器 / 队列 / 抢占

集群资源分配的策略层，决定利用率、公平性与故障恢复行为，是平台治理的主战场。

装箱 Bin packing

把不同规格的负载塞进异构算力池的策略，是推理与训练混部能否成立的前提。

Gang Scheduling

分布式作业的所有节点同时就绪才启动，避免部分占用导致的资源死锁与碎片。

拓扑感知调度

按 GPU、NUMA 节点与机架位置分配任务，降低跨域通信开销。

多租户 / 配额 / 抢占式实例

共享集群的隔离与公平机制；抢占式实例成本低但可能被随时收回，适合可中断负载。

TCO Total cost of ownership

总拥有成本，含硬件、机房、电力、网络与运维；自研与采购的对比应以同一口径计算。

每瓦每秒 token

把能效与产出绑定的指标，已取代单纯的 FLOPS，成为 AI 基础设施的主要衡量口径。

E · 软件与推理栈11 条

推理引擎

面向生成式模型优化的服务框架（vLLM、SGLang、TensorRT-LLM 等），核心能力是调度与显存管理。

PagedAttention

用分页方式管理 KV Cache，避免传统连续分块带来的显存碎片浪费。

前缀缓存 Prefix caching

复用相同前缀的 KV Cache，在多轮对话与共享系统提示场景下可显著降低算力与带宽成本。

上下文窗口与上下文压缩

长上下文带来 KV Cache 膨胀，压缩、摘要与外部记忆是主要的缓解手段。

算子与 Kernel Operator

矩阵乘法等计算在具体后端上的实现。算子库的深度与质量直接决定框架的硬件利用率。

编译器栈 XLA, Triton

把模型图编译为加速器指令的链路，决定了性能优化的可达上限，也决定换硬件的改造量。

分布式训练框架 FSDP, Megatron

负责张量/数据并行下的切分、通信与检查点管理，是大规模训练的工程底座。

梯度累积与微批次

用更小的 micro-batch 累积梯度以模拟大 batch 效果，是省显存的经典手段。

检查点与容错

长训练或长会话周期下，从硬件或软件故障中恢复状态的机制。

SLO / SLA / 配额

服务目标、对外承诺与资源上限的三层约束，平台必须能分别度量与触发。

可观测性 Metrics / Logs / Trace

定位推理时延与失败根因的基础；没有分段可观测性，成本治理无从谈起。

F · Agent 与平台9 条

Agent Loop

感知—推理—行动—反馈的闭环。每一轮都要重新读取上下文，是成本被放大的根源。

工具调用 Tool / Function calling

模型以结构化方式请求外部能力。参数校验、幂等性与错误语义是平台的责任，而非模型的。

MCP

模型与外部工具、数据源之间的标准化连接协议，解决每个应用重复造轮子的问题。

A2A Agent-to-agent

Agent 之间的通信与委派协议，解决跨主体协作、任务交接与身份信任问题。

上下文与记忆分层

会话内上下文、长期记忆与外部检索分层管理，决定「记得住」与「花得起」能否兼得。

幂等 / 超时 / 重试

工具调用的可靠性三件套。它们是否做对，直接决定 Agent 失败时的放大程度。

多 Agent 并发与扇出

并发子 Agent 会让上下文与工具调用呈扇出式增长，KV Cache 与并发度是主要成本项。

冷热分层

热数据放 HBM/GPU、冷数据放 DDR/SSD，用可接受的延迟换取明显的成本下降。

资源池化 Pooling

把加速器、内存与网络抽象为可切分、可复用的共享资源，提升整体利用率。

G · 工业革命与时代15 条 · 背景坐标系

工业革命 Industrial Revolution

以一项通用技术的普及为标志，生产方式、生产组织与社会结构被整体改写的过程。分期口径并不统一；本套文档采用中国通行口径：18 世纪 60 年代、19 世纪 70 年代、20 世纪四五十年代、2010s 起的智能化浪潮。

电子计算机 Electronic Computer

第三次工业革命的核心标志物，也是理解「可编程性」最好的样本。本文档统一用此口径而非「电脑」——电脑通常只指个人计算机（PC），而电子计算机涵盖从 ENIAC 到 AI 工厂的完整谱系；这也正是本套文档八次架构跃迁所追踪的对象。

通用电子计算机 General-purpose Computer

能通过存储程序执行不同任务的电子计算机（冯·诺依曼机，1945 报告提出）。「通用」二字是第三次革命的前提：正因同一台机器能跑不同程序，才谈得上「复制一份行为几乎不花钱」。

第三次科技革命

中国教材口径：以原子能、电子计算机、空间技术与生物工程的兴起为标志，起点取 20 世纪四五十年代，核心标志是电子计算机的广泛应用。与「第三次产业革命」（1970s 起的信息技术）并非完全同义。

通用技术 General Purpose Technology

会渗透到多数行业并引发组织与制度变化的技术（蒸汽机、电力、信息技术）。只有通用技术才能改写生产方式，而不只是提效。

信息时代 Information Age

以信息成为与物质、能源并列的核心资源为特征的时代。托夫勒《第三次浪潮》1980 最早提出，卡斯特尔斯《网络社会的崛起》1996 定型。

后工业社会 Post-industrial Society

贝尔 1973《后工业社会的来临》：经济重心从制造转向服务，知识与专业角色成为主导。它讲的是产业结构，不是「信息资源」。

知识经济 Knowledge Economy

德鲁克 1993：知识是最能增值的生产要素。它讲的是要素地位，与信息时代的「资源结构」判断不是一回事。

数字经济 Digital Economy

由数字技术驱动、以数据要素为核心的经济形态。侧重「驱动力与形态」，常被当作信息时代的操作化版本使用。

第四次工业革命 Industry 4.0

2010s 起的智能化浪潮：AI、物联网、机器人与数字孪生进入生产系统。分水岭在系统自主性，而非单纯自动化。「工业4.0」一词 2011 年源自德国汉诺威展，是制造业政策概念。

泰勒制 / 科学管理 Taylorism

第二次工业革命的组织维度标志：把作业拆解、计时、标准化与考核，以牺牲熟练工人的自主性换取可复制的流水线效率。

功能固着 Functional fixity

David 用于解释电气化迟滞的概念：管理者把旧流程的形状当成技术本身的一部分，于是只做替换而不做重排。换马达不换布局，等于什么都没变。

单元驱动 Unit drive

每台机器配自己的电动机，从而摆脱中央传动轴的布局约束，机器可按物料流向排列。第二次革命生产率爆发的真正开关，与今天的「流程重构」是同一个动作。

生产率 J 曲线 Productivity J-curve

Brynjolfsson 等提出：重组期先付出成本、后收获收益，测得生产率先下探再陡升。短期看不到收益是重组的正常形态，不是失败的信号。

恩格斯停顿 Engels' Pause

Allen 量化：1780–1840 年英国劳均产出 +46%，实际工资仅 +12%。技术收益与分配收益是两件事，后者有自己的时间表——直到 1860 年后工资增速反超产出增速，「共享增长」才确立。
