核心结论

电脑技术史 = 「通用化 → 专用化 → 可定制化」与「单机 → 集群 → AI 工厂」两条曲线的叠加。

架构的每次跃迁都不是单纯把机器做得更快，而是重新分配了「算力」与「数据搬运」的比重。 当算力不再稀缺，内存容量、互连带宽与电力供给就成了新的稀缺资源。因此今天评价一套计算系统， 衡量对象已从单颗芯片的 FLOPS，转向每瓦每秒产出多少 token、每个 token 的端到端成本、以及异构资源被调度的效率。

而这一切的位置感来自更外层：电脑是第三次工业革命的核心标志物，它的普及定义了信息时代。 三次革命依次替代体力、肌肉、认知，当下正在发生的第四次走向自主决策—— 详见下面的坐标系与 01 发展路径。

00

坐标系：电脑站在第几轮工业革命里

先定位，再往下看

电脑是第三次工业革命的核心标志物——第三次科技革命四大发明之一（原子能、电子计算机、空间技术、生物工程）， 也是其中唯一仍在持续演进的那一个；它的普及又直接定义了信息时代。 两个说法不矛盾：工业革命讲的是生产方式的变革，信息时代讲的是资源结构的变化， 电脑是同时落在两层上的具体技术载体。

三次革命分别替代体力、肌肉、认知。按产业经济学口径正在进入的第四次，替代的是自主决策—— 从辅助人决策，转向系统自主拆解与执行；而 Agent 平台正好压在这条分界线上。 四轮革命的完整史实主线（前两次不再只给摘要）、第三次革命内部的八次架构跃迁，以及各轮的代价与分配后果，见 01 发展路径； 把四轮压成可复用的规律与铁律，见 05 工业革命的逻辑。

01

三条核心判断

如果只记三句话，记这三条
01

算力已经过剩，数据搬运与电力才是稀缺资源

近 20 年峰值算力增长约 60 万倍，DRAM 带宽只增长约 100 倍，互连带宽只增长约 30 倍。大多数算力在等数据——这就是内存墙。评价系统的正确视角，是「每瓦每秒 token」，而不是峰值 FLOPS。

02

专用化不可逆，代价是生态碎片化

从 x86 通用到 GPU/ASIC 专用，再到 RISC-V + Chiplet 可定制，效率一路提升，但每一步都在制造新的迁移成本。ISA 只是契约，真正决定迁移成本的是编程模型与库生态——CUDA 正是靠后两者锁住生态。异构化的账单迟早要付，最好现在付。

03

Agent 的成本结构既不同于训练，也不同于传统请求

Agent 负载是算力密集 + 控制密集 + I/O 密集三者并存：推理吃 GPU 的带宽与显存，任务拆解、工具调用、权限校验吃 CPU 与内存。只按「GPU 卡时」做资源画像，会系统性高估利用率、低估真实瓶颈。

02

三条主线：演进的骨架

八段历史可压缩成这三行

每次「解决瓶颈」的做法都是把复杂度推向上一层：多核逼出并发编程，GPU 逼出编程模型与库，集群逼出分布式一致性，AI 工厂逼出调度与成本治理。 技术债不会消失，只会换一层楼继续住。详细拆解见 底层架构与影响。

约束一：内存墙

算力、内存带宽、互连带宽的增速已经脱节——这正是 AI 芯片「买了却用不满」的原因。

折算 20 年：算力约 60 万倍、DRAM 带宽约 100 倍、互连约 30 倍（Gholami et al., 2024）。

算力扩张速度事实上受制于 12–18 个月前签下的内存长约，而不受制于芯片设计。

约束三：ISA 格局松动，但生态是硬门槛

RISC-V 处理器份额
≈25%

2026 年的三个标志性进展：RVA23 服务器平台规范 1.0（2026-06）统一了 UEFI/ACPI、PCIe/IOMMU、BMC、RAS 与安全启动，让跨品牌部署成为可能； CPU 直连 GPU（RISC-V 经 NVLink Fusion 与 NVIDIA GPU 硬件级互连）使其进入 AI 数据中心核心链路； 边缘与车载规模化（车规 RISC-V 已量产上车）。 但三道门槛同时存在：各家自定义扩展互不兼容、软件适配周期常超一年、晶圆产能排产优先级低。

04

对 Agent 平台建设的 5 条推论

基于架构事实的推论，落地前需结合真实负载校验
01

Agent 的成本模型不是「卡时」，是「token 成本 + 内存占用」推论

长上下文、多轮工具调用、并发子 Agent 会同时放大两件事：KV Cache 的内存占用与解码阶段的带宽需求。这意味着上下文压缩、分层缓存、prefill/decode 分离路由属于平台级能力，而不是应用侧可以各自实现的技巧——否则每个应用都会重复踩一遍内存墙。

02

CPU 不是配角，Agent 的大部分时间花在控制流上推论

任务拆解、工具调用、权限校验、结果解析、跨系统编排，本质是控制密集与 I/O 密集负载，落在 CPU 与内存上；而 LLM 推理落在 GPU 上。如果平台按「GPU 卡时」单一维度做资源画像，就会系统性高估利用率、低估真实瓶颈。CPU/GPU 分池 + 按请求阶段做资源画像，比统一队列更贴合真实负载。

03

推理后端必须可替换，否则硬件代际切换会变成平台级事故推论

路线图上 2026/2027/2028 每年一代平台，每代更换内存代际与互连标准。把推理引擎、调度策略与硬件形态解耦（模型服务层可替换、算子与量化路径可替换），让硬件代际切换退化为配置变更而非架构改造。这是「专用化不可逆」这条主线的直接推论。

04

可移植性现在做，比未来迁移便宜得多推论

RISC-V 与各类自研 ASIC 的现实路径是「先在应用与模型层兼容，再谈 ISA 层」——指令集迁移的主要成本是软件生态，而软件生态的重建通常需要一年以上。平台侧现在就把模型服务、向量检索、工具协议与具体加速器解耦，是把未来成本前置到今天的低息投入。

05

把「每瓦每秒 token」引入平台级 SLO推论

行业衡量指标已从 FLOPS 转向能效与吞吐比。对平台而言，可落地的对应物是单位资源的有效产出：单个推理节点的有效 token 产出、显存与内存的占用率、以及不同推理形态（短问答 / 长上下文 / 多 Agent 并发）各自的成本曲线。把这些变成可观测、可分账的指标，比单看 QPS 更接近真实成本。

05

高频术语速查

20 条 · 完整 98 条术语表

内存墙 Memory wall

算力增速远超内存带宽增速，导致计算单元在等数据。

存储层次 Memory hierarchy

寄存器→缓存→主存→SSD→远端存储的层级，靠局部性做出等效扩容。

缓存三要素 Cache

命中时间、缺失率、容量，决定访存是纳秒级还是百纳秒级。

算术强度 Arithmetic intensity

每搬 1 字节能做多少次运算，决定负载是算力受限还是带宽受限。

Roofline 模型

用可达算力与内存带宽两条线界定性能上限。

HBM High Bandwidth Memory

垂直堆叠 DRAM 与加速器同封装，靠超宽接口而非高频率取胜。

NUMA Non-uniform memory access

内存按节点绑定，跨节点更慢；远端内存带宽是集群扩展的真实上限。

CUDA

NVIDIA 的并行计算平台与编程模型，本身即护城河。

量化 Quantization

用更低位宽表示权重与激活，以降低显存与带宽需求。

KV Cache

缓存已生成 token 的键值对，推理显存占用的头号来源。

预填充与解码 Prefill / Decode

前者算力密集，后者带宽密集，是分离部署的前提。

连续批处理 Continuous batching

请求完成即补入新请求，直接决定吞吐与排队时延。

推理引擎

面向生成式模型优化的服务框架，核心是调度与显存管理。

前缀缓存 Prefix caching

复用相同前缀的 KV Cache，多轮与共享提示场景省下大量成本。

Scale-up / Scale-out

同域扩加速器 / 跨节点扩集群，出域即从芯片互连变成网络问题。

装箱 Bin packing

把不同规格负载塞进异构算力池，是训练推理混部的前提。

TCO Total cost of ownership

硬件、机房、电力、网络与运维的总账，自研与采购须同口径比较。

每瓦每秒 token

把能效与产出绑定的指标，已取代单纯 FLOPS 成为主要口径。

Agent Loop

感知—推理—行动—反馈闭环，每轮都重读上下文，成本被放大的根源。

MCP / A2A

模型接工具、Agent 接 Agent 的两类标准化协议，解决重复造轮子与跨主体委派。
