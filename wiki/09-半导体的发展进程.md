# 半导体的发展进程

> 第三次革命的核心标志物，它自己的进程史。
> 与 [06 电子计算机八次跃迁](06-电子计算机八次跃迁.md) 的关系：八次跃迁讲的是**架构怎么变**，本文讲的是**让架构得以变的那个东西怎么变**。

---

## 一句话

**半导体的进程不是「芯片越来越小」这一条线，而是「缩放的载体换了三次」** —— 从平面搬到垂直，再从芯片搬到封装。

---

## 一、核心：缩放方式的三次转移

### 第一次：几何缩放（1965–2010）

把平面上的线做得更细。

| | |
|---|---|
| **理论支撑** | 摩尔定律（1965）：每年晶体管数翻倍；登纳德缩放（1974）：电压与电流随尺寸一起下降 |
| **代表工艺** | 平面工艺（1959）· 集成电路 · 微处理器（1971）· VLSI · 光刻 g 线 / i 线 → 193nm ArF |
| **节点节奏** | 90nm（2004）· 65nm（2006）· 45nm（2008）· 32nm（2009）· 28nm（2010） |
| **解决了什么** | 单位面积算力持续翻倍，单位能耗持续下降 —— 整轮第三次革命的地基 |
| **撞上了什么** | 约 2005 年前后尺寸缩放放缓；互连延迟与漏电先撞墙（不是逻辑，是线）；DUV 单次曝光逼近波长极限 |

**这一段是半导体贡献最大的时期**：没有它，后面的一切都不成立。

### 第二次：三维缩放（2011–2022）

把电路从平面立起来。

| | |
|---|---|
| **代表工艺** | FinFET（2011–2016，鳍式沟道 + 三维栅控）· EUV 首量产（2019，13.5nm 反射式光刻）· GAA nanosheet（2022，环绕栅极）· 背面供电（BSPDN）· 高 k / 低 k 材料 |
| **节点节奏** | 16/14nm（2015）· 10nm（2017）· 7nm（2018）· 5nm（2020）· 3nm（2022） |
| **解决了什么** | 把平面缩放放弃的电压与漏电重新拿回来，换来继续缩小的许可 |
| **撞上了什么** | 工艺步骤与成本指数上升、良率承压；EUV 设备单点集中，产能即瓶颈；3nm 以下只剩 GAA 一条路 |

### 第三次：封装缩放（2017– ）

不再追求一颗大芯片，改为一堆小芯片。

| | |
|---|---|
| **代表工艺** | CoWoS（2017，2.5D 中介层）· Chiplet（2017，不同模块各自最优工艺）· HBM（2016 → HBM4 2026，16 层 / 2048-bit）· 混合键合（SoIC 6μm，逻辑侧已量产；内存侧推迟到 HBM4E / HBM5）· CPO（2026 首批量产） |
| **解决了什么** | 绕开 reticle 858mm² 与良率乘积 —— 把「一颗芯片」拆成一堆芯片 |
| **撞上了什么** | CoWoS 产能缺口 10–20%，多数新增产能要到 2027–2028 才释放；键合良率、翘曲与测试成本上升；热与电力成为新的天花板 |

**注意第三次转移与前两次不同**：前两次是「同一种东西做得更细」，第三次是「换一种堆法」。

---

## 二、光刻是主线

每一次换波长，都是为了在更小的图形上仍能成像。

| 波长 | 年代 | 意义 |
|---|---|---|
| g 线 436nm | 1970s | 接触式 / 投影式曝光起步 |
| h 线 405nm | 1980s | 分辨率提升 |
| i 线 365nm | 1980s | 更短波长继续缩小 |
| ArF 193nm | 1990s | DUV 时代开启，单次曝光做不出更小图形 |
| 浸没式 ArF 193nm | 2004 | 超纯水压缩折射率，多重曝光撑住 90–7nm |
| **EUV 13.5nm** | **2019 量产** | 反射式掩模，**首次突破波长限制** |

**两个拐点**：

- **约 2005 年前后** —— 制程红利放缓，靠缩小单个器件拿不到性能了
- **2019 年** —— EUV 量产，图形化第一次不再受波长限制

**但节点号仍在按节奏前进**：90nm 用了约 8 年，14nm → 7nm 约 3 年，7nm → 2nm 约 7 年。**节奏变慢不是因为做不出来，而是每一步都要更贵的设备和更难的良率。**

## 三、存储与封装：第三条线的另一半

| 维度 | 关键节点 |
|---|---|
| **DRAM** | 1970s 缩放起步 → 突发式架构 → 2016 HBM 登场 |
| **NAND** | 东芝舛冈富士雄 1980 提出浮栅 → 层数竞赛（YMTC 232 层） |
| **HBM** | 2016 HBM2 / 2022 HBM3 / 2023 HBM3E / **2026 HBM4**（2048-bit，接口较 HBM3 翻倍） |
| **中介层** | 1.5 倍光罩（CoWoS 初代）→ 3.3 倍 → 9 倍（Rubin 代）→ 14 倍以上 → 晶圆级（40 倍光罩） |
| **混合键合间距** | 微凸点历史约 40μm → 最新存储约 10μm；混合键合前沿 **6μm**（SoIC），路径到 4.5μm（2029），研发已演示亚微米 |

**HBM 的特殊地位**：严格说它是 DRAM 而不是逻辑半导体，但对 AI 的约束力已经超过逻辑制程。2026-01 JEDEC 放宽 HBM 堆叠高度上限（775μm），HBM4 16 层可继续用微凸点 —— 混合键合因此被推迟到 HBM4E / HBM5。

## 四、产业分工的进程

半导体的进程不只是工艺的进程，也是**分工的进程**：

| 阶段 | 分工形态 | 标志 |
|---|---|---|
| 1950s–1970s | **IDM**（设计 + 制造 + 封装一体） | 英特尔、TI、德州仪器 |
| 1980s | **设计与制造分离**，出现纯代工模式 | 台积电 1987 成立 |
| 1990s–2000s | **设计 / 制造 / 封测 / 设备 / 材料 / IP / EDA** 各自成链 | Arm 的 IP 授权模式；Cadence / Siemens EDA |
| 2010s– | **设计公司 + 代工寡头 + 设备单点** | 台积电先进制程与 CoWoS 双卡脖子；ASML 的 EUV 独家 |
| 2020s– | **异构集成成为主战场** | Chiplet 标准（UCIe）、CPO |

**这条分工史解释了为什么今天「卡脖子」的往往不是设计而是设备与产能**：设计可以靠人才追赶，设备与产能不能。

## 五、中国的位置（口径必须分清）

**这一节最容易被误读，因为「自给率」在不同来源之间差了一个数量级 —— 差的不是事实，是分子分母。**

| 口径 | 数值 | 说明 |
|---|---|---|
| **集成电路产量自给率** | **70%**（截至 2026-06） | 高盛口径，指中国产出的芯片能满足本土需求的比重；2010-01 仅 38% |
| 芯片自给率（狭义） | 25–30% | SIA / IC Insights 一类口径 |
| 半导体**设备**自给率 | 约 21%（2025）→ 35%（2026-01，限 28nm 及以上成熟制程） | 指国产设备在本土产线的份额 |
| **光刻整机**国产化率 | 约 1% | 差距最大的一环 |

**产能结构**（截至 2025）：中国大陆 29 座 8 吋厂 + 50 座 12 吋厂，整体晶圆产能约占全球 20%；其中 **90–28nm 成熟制程占 68.3%，110nm 及以上占 30%，14nm 及以下先进制程仅占 1.7%**。

**卡在哪**：EUV 无法出口 → 只能用 DUV 多重曝光 → 步骤增加、成本上升、良率下降。高盛模型估中芯先进制程良率 2026 年约 23%，对照台积电 7nm 超过 90%。

**进展（2026）**：

- **国产浸没式 DUV 开始小批量交付**：The Information 2026-07 报道，预计 2026 年交付约 5 套、2027 年约 20 套给中芯国际、华虹、长鑫；国产 EUV 仍在原型阶段
- **先进封装与三维堆叠是绕道**：业界正用 Chiplet、混合键合、晶圆堆叠来补性能差距 —— 这正是第三条线（封装缩放）给落后者留的门
- 存储侧自给率从 2020 年不足 5% 提升至 2026 年约 35%（长鑫、长江存储）

**口径提醒**：把「产量自给率 70%」与「先进制程占比 1.7%」放在一起看，才不会误判。**成熟制程的自给是真的，先进制程的差距也是真的，两者不矛盾。**

## 六、前方：已查证到判定条件

| 岔路 | 现状 | 判定条件 | 仍不确定 |
|---|---|---|---|
| **混合键合 vs 微凸点** | 逻辑侧已量产（SoIC 6μm、Foveros Direct 9μm），内存侧被推迟 | JEDEC 2026-01 放宽高度上限（775μm）→ 混合键合推迟到 HBM4E / HBM5 | 逻辑堆叠现量产仅 2–3 层；8–16 层仍在论文阶段 |
| **定制 ASIC vs 通用 GPU** | 定制 ASIC 出货增速 44.6% 首超商用 GPU 的 16.1%；NVIDIA 仍约占 70% | 工作负载是否固定 | 架构换代则已定制的硅成沉没成本 |
| **浸没式 vs 冷板** | 冷板占 2025 年中国液冷数据中心市场 93.5% | 单柜 >200kW 时浸没才占优；6 年 TCO 交叉点 | 冷却液工质无统一标准 |

## 七、它对第三次革命意味着什么

**半导体的进步第一次快过了整个系统的进步。**

跃迁 7（2023–2026）是八次里第一次「算力过剩」：算力两年翻 3 倍，内存带宽只涨 1.6 倍、互连只涨 1.4 倍。**卡住的不是晶体管，是 HBM、电力和封装产能。**

这解释了第四次的结构为何是「云端算力 + 口袋终端 + 工具协议」：模型在云端跑（半导体），经互联网分发（连接线），由终端接入（移动设备），而**平台设计的前置约束是产能与电力配额 —— 这是平台设计的前置约束，不是上线后的运维问题**。
