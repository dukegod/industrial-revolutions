# 核心知识体系 · Wiki

本目录是这套文档的**知识本体**：把散在可视化页面里的结论、机制与数据，沉淀成可检索、可引用、可单独阅读的 Markdown。

与 `visualization/` 的关系是**知识 → 呈现**，不是复制：

| | `wiki/` | `visualization/` |
|---|---|---|
| 形态 | Markdown（纯文本，可 diff、可 grep、可被 Agent 引用） | HTML（图表化、带树形导航、适合阅读与演示） |
| 定位 | **结论与依据的权威来源** | 结论的可视化表达 |
| 更新 | 事实变了先改这里 | 再跑 `scripts/build.py` 同步页面 |

## 核心论点（如果只记五句话）

1. **人类发展的动力，是「把稀缺变成不稀缺」；每一轮发展的代价，是把新的稀缺制造出来。**
2. **四轮革命是同一个答案的四个版本**：把人类的一部分能力，转成可复制、可规模化、可低成本调用的外部资源。
3. **技术可用 ≠ 生产率兑现，中间隔着一次组织重构**（电气化约 40 年、计算机约 15 年）。
4. **重组期先付成本、后收获收益**——收益曲线是 J 形，不是直线。
5. **技术收益与分配收益是两件事**，后者有自己的时间表（1780–1840 英国：产出 +46%、工资仅 +12%）。

## 维护约定

- **事实先入 wiki**：新增或修正事实时，先改 `wiki/` 下对应条目，标注来源与时间。
- **口径必须声明**：分期、统计口径、编者归纳与有据可查的部分要分开写（见 [08 数据来源与口径](08-数据来源与口径.md)）。
- **页面由脚本同步**：改完 wiki 后跑 `python3 scripts/build.py` 更新页面，再跑 `python3 scripts/verify.py` 确认无回归。
- **不确定就写不确定**：查不到一手出处的，写「未能验证」而不是绕过。
