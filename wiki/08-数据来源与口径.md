### 这三个岔路的口径冲突与取舍

- **液冷份额口径差异很大**：赛迪以数据中心侧系统与配套为锚、中商以服务器整机内液冷价值量为准，两者增速方向一致但绝对值不同；**浸没式占比在不同来源间从约 3% 到约 34% 不等**。本套文档采用赛迪的「数据中心液冷市场」口径（冷板 93.5%），**并明确它是这个市场里的份额，不是全行业占比**。
- **有科普类文章称「2026 年浸没式液冷在新建智算中心全面普及」**，与赛迪 93.5% 冷板份额直接矛盾 —— **不予采纳**，属宣传性表述。
- **定制 ASIC 与 GPU 的增速对比（44.6% vs 16.1%）是研究机构估算**，按台数还是按金额计算会得出不同结果，本套文档只把它当作「定制化增速已超过通用」的定性结论使用。
- **华为 LogicFolding / τ 定律**（2026-05）为厂商自报 + ChinaXiv 预印本，密度 +55%、等性能下 NPU/GPU/CPU 分别降 66%/58%/41% 等数字**未经独立验证**，本套文档只提「逻辑堆叠的热与良率是攻关重点」这一定性结论，**不引用其性能数字**。
- **OpenAI「Jalapeño」与 Anthropic-三星接洽均处于发布/洽谈阶段**，不是已交付的量产产品。

| PwC / AI Index 的采用率与收益数据 | **横截面调研自报**，反映当期感知，不能直接推出因果 |
| 「88% 组织采用」与「智能体部署个位数」 | **来自不同口径**，不可相减 |
| 「RISC-V ≈25% 份额」 | 处理器颗数口径（非营收），高度集中于嵌入式与物联网，高端通用计算仍由 x86/ARM 主导 |
| 「德国口径 1947–2011 / 2011–」 | 本套文档**不采用**，仅在口径对照中列出 |
| 「替代弹性上升导致共享增长」 | 是对 Allen 机制的**通俗化表述**；严格说，共享增长的直接机制是资本积累追上了技术进步的要求 |
| 2027 / 2028 平台规格 | NVIDIA **路线图口径**，非交付承诺 |
| **IEA 两份报告的用电数字** | ✅ **已核一手 PDF**（见第二节之二）。注意 `iea.org` HTML 页对命令行返回 403，但 Blob 直链可下载 PDF |
| **IEA 950 与 945 的差异** | ⚠️ **同一份 2026 报告内**：正文用 **950**，附录 Table A.4 用 **945**。引用须注明正文还是附录 |

| **AI 专用 2025 年基数「约 155 TWh」** | ❌ **一手报告未给该数值**，不予采用 |
