## 一、分期口径（最容易出错的地方）

| 名词 | 要点 |
|---|---|
| **工业革命** | 以一项通用技术的普及为标志，生产方式、生产组织与社会结构被整体改写。**分期口径并不统一**，引用前须声明所用口径 |
| **第三次科技革命** | 中国教材口径：以原子能、**电子计算机**、空间技术与生物工程的兴起为标志，起点取 20 世纪四五十年代，核心标志是**电子计算机的广泛应用** |
| **第三次产业革命** | 产业经济学口径：1970s 起的信息技术革命。**与上一条并非完全同义** |
| **第四次工业革命** | 2010s 起的智能化浪潮：AI、机器人、量子信息等。分水岭在**系统自主性**，而非单纯自动化 |

**本套文档采用中国通行口径**：18 世纪 60 年代 / 19 世纪 70 年代 / 20 世纪四五十年代 / 2010s。

**其他常见口径（引用时须对齐）**：

| 来源 | 第三次 | 第四次 |
|---|---|---|
| 中国教材 | 20 世纪四五十年代 | 2010s 起 |
| Schwab / WEF | 1960s 起 | 世纪之交 |
| 产业经济学 | 1970s 起 | 2010s 起 |
| 德国 Industrie 4.0 | 1947–2011 | 2011 起 |

## 二、几个关键概念的辨析

| 名词 | 定义 | 为什么值得知道 |
|---|---|---|
| **电子计算机** | 第三次工业革命的核心标志物 | 「电脑」通常只指 PC；电子计算机涵盖 ENIAC 到 AI 工厂的完整谱系 |
| **通用电子计算机** | 能通过存储程序执行不同任务的电子计算机（冯·诺依曼机） | **「通用」是第三次革命的前提**：同一台机器跑不同程序，才谈得上零成本复制行为 |
| **通用技术** | 会渗透到多数行业并引发组织与制度变化的技术（蒸汽机、电力、信息技术） | 只有通用技术才能改写生产方式，而不只是提效 |
| **功能固着** | 把旧流程的形状当成技术本身的一部分，于是只做替换不做重排 | David 解释电气化迟滞的核心概念。换马达不换布局，等于什么都没变 |
| **单元驱动** | 每台机器配自己的电动机，摆脱中央传动轴的布局约束 | **第二次革命生产率爆发的真正开关**，与今天的「流程重构」是同一个动作 |
| **生产率 J 曲线** | 重组期先付出成本、后收获收益，测得生产率先下探再陡升 | **短期看不到收益是重组的正常形态**，不是失败的信号 |
| **恩格斯停顿** | 1780–1840 年英国劳均产出 +46%，实际工资仅 +12% | 技术收益与分配收益是两件事，后者有自己的时间表 |

## 三、技术侧高频词（速查）

**内存与带宽**：内存墙 · 存储层次 · 缓存三要素 · 算术强度 · Roofline 模型 · HBM · NUMA

**加速与并行**：CUDA · 量化 · KV Cache · 预填充与解码 · 连续批处理 · 投机解码

**推理栈**：推理引擎 · 前缀缓存 · Scale-up / Scale-out · 装箱 · TCO

**Agent 平台**：Agent Loop · 工具调用 · MCP · A2A · 上下文与记忆分层 · 幂等 / 超时 / 重试 · 多 Agent 并发与扇出 · 冷热分层 · 资源池化

**指标**：每瓦每秒 token —— 把能效与产出绑定的指标，已取代单纯 FLOPS 成为 AI 基础设施的主要衡量口径

## 四、指标口径提醒

| 指标 | 注意 |
|---|---|
| **每瓦每秒 token** | 取代 FLOPS 成为主流，但**不含分配端与组织重构的收益** —— 技术账不等于组织账 |
| **价值集中度（74%）** | 是 PwC 2026 调研的横截面自报数据，非因果结论 |
| **组织采用率（88%）** | 与「智能体部署个位数」来自不同口径，**不可相减** |
| **RISC-V 份额 ≈25%** | 处理器颗数口径，非营收口径，且高度集中于嵌入式与物联网 |
